### 1. 核心概念介绍

**多智能体协作系统（Multi-Agent Collaboration）** 是指多个AI智能体（Agent）协同工作，共同完成复杂任务的架构模式。与单一智能体不同，多智能体系统通过角色分工、任务分解和结果整合，能够处理更加复杂的业务场景。

#### 关键概念

| 概念 | 说明 |
|------|------|
| **智能体（Agent）** | 具有感知、决策和行动能力的独立AI实体 |
| **协作（Collaboration）** | 多个智能体之间的信息交换与任务协调 |
| **任务分解（Decomposition）** | 将复杂任务拆分为子任务分配给不同智能体 |
| **结果整合（Integration）** | 将多个智能体的输出合并为最终结果 |
| **协调器（Orchestrator）** | 负责任务分配和流程控制的中心组件 |

#### 常见协作模式

1. **层级模式（Hierarchical）**：一个主智能体协调多个子智能体
2. **对等模式（Peer-to-Peer）**：智能体之间平等协作，相互通信
3. **流水线模式（Pipeline）**：智能体按顺序处理，前一个的输出是后一个的输入
4. **市场模式（Market-based）**：智能体通过竞价机制获取任务

from abc import ABC, abstractmethod
from typing import Dict, Any
import openai

class BaseAgent(ABC):
    """所有智能体的基类"""
    
    def __init__(self, agent_id: str, name: str, system_prompt: str):
        self.agent_id = agent_id
        self.name = name
        self.system_prompt = system_prompt
        self.message_history = []
        self.client = openai.OpenAI()
    
    def receive_message(self, message: Dict[str, Any]):
        """接收消息并处理"""
        print(f"[{self.name}] 收到消息: {message['content'][:50]}...")
        response = self.process(message)
        return response
    
    @abstractmethod
    def process(self, message: Dict[str, Any]) -> Dict[str, Any]:
        """子类实现具体的处理逻辑"""
        pass
    
    def call_llm(self, prompt: str) -> str:
        """调用大语言模型"""
        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[
                {"role": "system", "content": self.system_prompt},
                {"role": "user", "content": prompt}
            ]
        )
        return response.choices[0].message.content

class ResilientCoordinator:
    """具备容错能力的协调器"""
    
    async def execute_with_retry(self, agent, message, max_retries=3):
        """带重试机制的任务执行"""
        for attempt in range(max_retries):
            try:
                result = await asyncio.wait_for(
                    asyncio.to_thread(agent.receive_message, message),
                    timeout=30  # 30秒超时
                )
                return result
            except asyncio.TimeoutError:
                print(f"⏱️ 尝试 {attempt + 1} 超时，重试中...")
            except Exception as e:
                print(f"❌ 尝试 {attempt + 1} 失败: {e}")
        
        # 所有重试失败，返回错误
        return {
            "error": "Max retries exceeded",
            "agent_id": agent.agent_id
        }

### 7. 常见问题解答

**Q1: 多智能体系统会增加多少延迟？**

A: 取决于架构设计。串行流程会累加延迟，但并行流程可以显著减少总体时间。建议使用异步编程和并行执行来优化性能。

**Q2: 如何处理智能体之间的冲突？**

A: 可以通过以下方式：
1. 明确定义每个智能体的职责边界
2. 引入仲裁智能体处理冲突
3. 使用投票机制做出决策
4. 设置优先级规则

**Q3: 多智能体系统的成本高吗？**

A: 成本确实会比单一智能体高，但可以优化：
1. 为简单任务使用较小的模型
2. 缓存中间结果避免重复计算
3. 按需调用智能体，非全量激活

**Q4: 如何调试多智能体系统？**

A: 建议采用：
1. 详细的日志记录每个智能体的输入输出
2. 可视化消息流（如使用Mermaid图）
3. 单元测试每个智能体独立功能
4. 使用断点检查中间状态

**Q5: 智能体数量有上限吗？**

A: 理论上没有硬性上限，但需要考虑：
1. 协调复杂度随数量增加
2. 上下文管理变得更加困难
3. 系统资源消耗

建议从一个协调器+3-5个专业智能体开始，逐步扩展。
