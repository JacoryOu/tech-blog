## 什么是AI智能体

**AI智能体（AI Agent）**是一种能够感知环境、自主决策并执行行动的智能系统。与传统的大语言模型（LLM）不同，AI智能体具备以下关键特性：

### 核心定义

> AI智能体是一个能够在其环境中自主运作、做出决策并采取行动以实现特定目标的智能系统。

### 与LLM的本质区别

| 特性 | 传统LLM | AI智能体 |
|------|---------|----------|
| 交互方式 | 单次对话 | 持续运行 |
| 工具使用 | 无法调用外部工具 | 可调用API、数据库等 |
| 任务执行 | 只能生成文本 | 可执行实际操作 |
| 记忆能力 | 单次会话记忆 | 可拥有长期记忆 |
| 决策能力 | 被动响应 | 主动规划决策 |

### 典型应用场景

1. **个人助理** - 管理日程、发送邮件、安排会议
2. **客服机器人** - 处理客户咨询、订单查询、售后支持
3. **研究助手** - 搜集信息、整理报告、数据分析
4. **编程助手** - 代码生成、调试、代码审查

## 为什么需要AI智能体

### 大模型的局限性

虽然GPT-4等大语言模型表现出色，但存在固有局限：

- **知识截止** - 训练数据有截止日期，无法获取实时信息
- **无法行动** - 只能生成文本，无法执行实际操作
- **计算能力弱** - 不擅长精确的数学计算和逻辑推理
- **无外部访问** - 无法查询数据库、调用API或操作文件

### AI智能体的价值

```
用户: "帮我查一下北京今天的天气，然后发邮件提醒我带伞"

传统LLM: "抱歉，我无法查询实时天气或发送邮件"

AI智能体: 
  1. 调用天气API获取北京天气 → "小雨，15°C"
  2. 调用邮件API发送邮件 → 完成
  3. 回复用户: "已查询到北京今日小雨，提醒邮件已发送至您的邮箱"
```

### ReAct模式

**ReAct（Reasoning + Acting）**是当前最流行的智能体设计模式：

```
Thought → Action → Observation → Thought → Action → ...
```

**循环流程：**
1. **思考（Thought）** - 分析当前情况，决定下一步
2. **行动（Action）** - 执行选定的工具/操作
3. **观察（Observation）** - 获取执行结果
4. **重复** - 直到任务完成

- **文件操作** - 读写文件、数据处理

#### 3. 记忆系统（Memory）

```
短期记忆（Short-term）

├── 事实记忆（向量数据库）
├── 情景记忆（历史对话）

```

## 实操案例：天气查询助手

### 完整代码实现

```python
import os
import json
import requests
from typing import Dict, List, Callable

class WeatherAgent:
    """天气查询AI智能体"""
    
    def __init__(self, openai_key: str, weather_key: str):
        self.openai_key = openai_key
        self.weather_key = weather_key
        self.tools = self._register_tools()
    
    def _register_tools(self) -> Dict[str, Callable]:
        """注册可用工具"""
        return {
            "get_weather": self._get_weather,
            "send_email": self._send_email,
        }
    
    def _get_weather(self, city: str) -> str:
        """查询城市天气"""
        url = f"https://api.weather.com/v1/current?city={city}&appid={self.weather_key}"
        try:
            response = requests.get(url, timeout=10)
            data = response.json()
            return f"{city}天气：{data['weather']}, {data['temperature']}°C"
        except:
            return f"{city}天气：多云，20°C (模拟数据)"
    
    def _send_email(self, to: str, subject: str, body: str) -> str:
        """发送邮件（模拟）"""
        print(f"📧 [模拟发送邮件]\n收件人: {to}\n主题: {subject}\n内容: {body}")
        return "邮件已发送"
    
    def _call_llm(self, prompt: str) -> str:
        """调用大语言模型"""
        headers = {
            "Authorization": f"Bearer {self.openai_key}",
            "Content-Type": "application/json"
        }
        data = {
            "model": "gpt-3.5-turbo",
            "messages": [{"role": "user", "content": prompt}]
        }
        try:
            response = requests.post(
                "https://api.openai.com/v1/chat/completions",
                headers=headers,
                json=data,
                timeout=30
            )
            return response.json()['choices'][0]['message']['content']
        except:
            return "I'm ready to help!"
    
    def run(self, user_input: str) -> str:
        """运行智能体"""
        # 步骤1：理解意图
        analysis_prompt = f"""
用户输入: {user_input}

分析用户的意图和需要执行的操作。可用工具：
1. get_weather(city) - 查询指定城市天气
2. send_email(to, subject, body) - 发送邮件

请判断：
- 用户需要什么信息？
- 需要调用哪些工具？
- 工具参数是什么？

以JSON格式回复：{{"intent": "...", "actions": [...]}}
"""
        analysis = self._call_llm(analysis_prompt)
        
        # 步骤2：执行工具
        results = []
        if "天气" in user_input:
            city = "北京"  # 简化处理，实际应用NLP提取
            weather = self._get_weather(city)
            results.append(weather)
        
        # 步骤3：生成回复
        response_prompt = f"""
用户问题: {user_input}
执行结果: {results}

请根据执行结果，用中文生成友好的回复。
"""
        return self._call_llm(response_prompt)

# 使用示例
if __name__ == "__main__":
    agent = WeatherAgent(
        openai_key=os.getenv("OPENAI_API_KEY"),
        weather_key=os.getenv("WEATHER_API_KEY")
    )
    
    response = agent.run("北京今天天气怎么样？")
    print(response)
```

## 进阶功能：记忆系统

### 简单记忆实现

```python
class AgentWithMemory:
    """带记忆功能的智能体"""
    
    def __init__(self):
        self.short_term_memory = []  # 短期记忆
        self.long_term_memory = {}   # 长期记忆
    
    def remember(self, key: str, value: str):
        """存储长期记忆"""
        self.long_term_memory[key] = value
    
    def recall(self, key: str) -> str:
        """回忆长期记忆"""
        return self.long_term_memory.get(key, "不记得了")
    
    def add_to_context(self, message: str):
        """添加到短期记忆"""
        self.short_term_memory.append(message)
        # 限制上下文长度
        if len(self.short_term_memory) > 10:
            self.short_term_memory.pop(0)
    
    def get_context(self) -> str:
        """获取对话上下文"""
        return "\n".join(self.short_term_memory)
```

### 向量数据库集成

```python
from sentence_transformers import SentenceTransformer
import numpy as np

class VectorMemory:
    """基于向量数据库的长期记忆"""
    
    def __init__(self):
        self.model = SentenceTransformer('all-MiniLM-L6-v2')
        self.memories = []
        self.embeddings = []
    
    def store(self, text: str):
        """存储记忆"""
        embedding = self.model.encode(text)
        self.memories.append(text)
        self.embeddings.append(embedding)
    
    def search(self, query: str, top_k: int = 3) -> List[str]:
        """语义搜索相关记忆"""
        if not self.memories:
            return []
        
        query_emb = self.model.encode(query)
        similarities = [
            np.dot(query_emb, emb) / (np.linalg.norm(query_emb) * np.linalg.norm(emb))
            for emb in self.embeddings
        ]
        
        top_indices = np.argsort(similarities)[-top_k:][::-1]
        return [self.memories[i] for i in top_indices]
```
