## 什么是AI智能体工具链

AI智能体（AI Agent）是一种能够自主感知环境、做出决策并执行行动的系统。要让智能体真正发挥作用，需要一套完整的工具链来扩展其能力边界。

### 工具链的核心组成

1. **感知层**：获取外部信息（API、数据库、传感器等）
2. **推理层**：大语言模型进行思考和决策
3. **执行层**：调用工具完成任务
4. **记忆层**：存储上下文和长期记忆

### 为什么需要标准化协议？

在没有统一标准之前，每个智能体框架都有自己的工具调用方式：
- LangChain 的 Tools
- AutoGPT 的 Commands
- OpenAI 的 Function Calling

这导致工具无法跨框架复用。MCP（Model Context Protocol）协议的出现解决了这个问题。

## MCP协议详解

MCP（Model Context Protocol）是由 Anthropic 推出的开放标准，旨在统一 AI 模型与外部工具、数据源之间的交互方式。

### MCP的核心概念

```
┌─────────────────┐     MCP协议      ┌─────────────────┐
│   AI 智能体      │ ◄──────────────► │   MCP服务器      │
│  (MCP客户端)     │                  │  (工具提供者)     │
└─────────────────┘                  └─────────────────┘
                                             │
                    ┌────────────────────────┼────────────────────────┐
                    ▼                        ▼                        ▼
              ┌─────────┐             ┌─────────┐             ┌─────────┐
              │ 文件系统 │             │ 数据库  │             │ 外部API │
              └─────────┘             └─────────┘             └─────────┘
```

### MCP的优势

1. **即插即用**：工具开发者只需实现一次 MCP 接口
2. **生态互通**：任何支持 MCP 的智能体都能使用这些工具
3. **安全可靠**：标准化的权限控制和资源隔离
4. **动态发现**：智能体可以自动发现和学习新工具

### MCP与Function Calling的区别

| 特性 | Function Calling | MCP |
|------|-----------------|-----|
| 标准化程度 | 厂商特定 | 开放标准 |
| 工具复用 | 困难 | 简单 |
| 安全沙箱 | 无 | 有 |
| 动态发现 | 不支持 | 支持 |
| 资源管理 | 无 | 完整的生命周期管理 |

## 常用工具集成

### 1. 文件系统工具

让智能体能够读写本地文件：

```python
from mcp.server import Server
import os

server = Server("filesystem-server")

@server.tool()
async def read_file(path: str) -> str:
    """读取文件内容"""
    with open(path, 'r') as f:
        return f.read()

@server.tool()
async def write_file(path: str, content: str) -> bool:
    """写入文件内容"""
    with open(path, 'w') as f:
        f.write(content)
    return True

@server.tool()
async def list_directory(path: str) -> list:
    """列出目录内容"""
    return os.listdir(path)
```

### 2. 数据库查询工具

```python
import sqlite3

@server.tool()
async def query_database(query: str, db_path: str = "data.db") -> list:
    """执行SQL查询"""
    conn = sqlite3.connect(db_path)
    cursor = conn.cursor()
    cursor.execute(query)
    results = cursor.fetchall()
    conn.close()
    return results

@server.tool()
async def get_table_schema(table_name: str, db_path: str = "data.db") -> dict:
    """获取表结构信息"""
    conn = sqlite3.connect(db_path)
    cursor = conn.cursor()
    cursor.execute(f"PRAGMA table_info({table_name})")
    schema = cursor.fetchall()
    conn.close()
    return {"columns": schema}
```

### 3. Web搜索工具

```python
import requests

@server.tool()
async def web_search(query: str, num_results: int = 5) -> list:
    """执行网络搜索"""
    # 使用 Brave Search API
    api_key = os.getenv("BRAVE_API_KEY")
    url = "https://api.search.brave.com/res/v1/web/search"
    headers = {"X-Subscription-Token": api_key}
    params = {"q": query, "count": num_results}
    
    response = requests.get(url, headers=headers, params=params)
    data = response.json()
    
    results = []
    for item in data.get("web", {}).get("results", []):
        results.append({
            "title": item["title"],
            "url": item["url"],
            "description": item["description"]
        })
    return results
```

### 4. 代码执行工具

```python
import subprocess
import tempfile

@server.tool()
async def execute_python(code: str) -> dict:
    """安全执行Python代码"""
    with tempfile.NamedTemporaryFile(mode='w', suffix='.py', delete=False) as f:
        f.write(code)
        temp_file = f.name
    
    try:
        result = subprocess.run(
            ['python3', temp_file],
            capture_output=True,
            text=True,
            timeout=30
        )
        return {
            "stdout": result.stdout,
            "stderr": result.stderr,
            "returncode": result.returncode
        }
    except subprocess.TimeoutExpired:
        return {"error": "代码执行超时"}
    finally:
        os.unlink(temp_file)
```

## n8n工作流设计

n8n 是一个开源的工作流自动化工具，可以与 MCP 协议结合，构建复杂的 AI 智能体工作流。

### n8n + MCP 集成架构

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  触发器      │───▶│  n8n工作流   │───▶│  AI节点      │
│ (Webhook/   │    │             │    │ (LLM调用)   │
│  定时/手动)  │    │  • 数据转换  │    │             │
└─────────────┘    │  • 条件分支  │    └──────┬──────┘
                   │  • MCP调用   │           │
                   └─────────────┘           ▼
                                        ┌─────────────┐
                                        │  MCP服务器   │
                                        │  • 文件操作  │
                                        │  • 数据库    │
                                        │  • API调用   │
                                        └─────────────┘
```

### 实战：创建MCP工具节点

在 n8n 中使用 HTTP Request 节点调用 MCP 服务器：

1. **配置 HTTP Request 节点**
   - Method: POST
   - URL: `http://localhost:3000/mcp/call`
   - Headers: `Content-Type: application/json`
   - Body:
   ```json
   {
     "tool": "read_file",
     "params": {
       "path": "/data/report.txt"
     }
   }
   ```

2. **错误处理**
   - 添加 IF 节点检查返回状态
   - 配置重试逻辑（最大3次）
   - 失败时发送通知

### 常用n8n节点组合

#### 场景1：智能文档处理

```
[Webhook] → [读取文件] → [MCP-文档解析] → [AI-提取关键信息] → [MCP-写入数据库] → [发送通知]

[Telegram消息] → [AI-理解意图] → [IF-需要查询]

                    │
                    └─No─────────→ [AI-直接回复]
                                    │
                                    ▼
                              [发送回复消息]
```

## 实战案例：智能客服系统

### 系统架构

构建一个能够处理订单查询、退换货申请、常见问题解答的智能客服系统。

```python
# customer_service_agent.py
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from openai import AsyncOpenAI

class CustomerServiceAgent:
    def __init__(self):
        self.client = AsyncOpenAI()
        self.mcp_session = None
        self.tools = []
    
    async def connect_to_mcp(self):
        """连接到MCP服务器"""
        server_params = StdioServerParameters(
            command="python",
            args=["mcp_order_server.py"],
            env=None
        )
        
        async with stdio_client(server_params) as (read, write):
            self.mcp_session = ClientSession(read, write)
            await self.mcp_session.initialize()
            
            # 获取可用工具列表
            tools_result = await self.mcp_session.list_tools()
            self.tools = tools_result.tools
    
    async def process_message(self, user_message: str) -> str:
        """处理用户消息"""
        # 调用LLM进行意图识别
        response = await self.client.chat.completions.create(
            model="gpt-4",
            messages=[
                {"role": "system", "content": self.get_system_prompt()},
                {"role": "user", "content": user_message}
            ],
            tools=self.format_tools_for_openai(),
            tool_choice="auto"
        )
        
        message = response.choices[0].message
        
        # 检查是否需要调用工具
        if message.tool_calls:
            tool_call = message.tool_calls[0]
            tool_result = await self.execute_tool(
                tool_call.function.name,
                tool_call.function.arguments
            )
            
            # 将工具结果返回给LLM
            final_response = await self.client.chat.completions.create(
                model="gpt-4",
                messages=[
                    {"role": "system", "content": self.get_system_prompt()},
                    {"role": "user", "content": user_message},
                    {"role": "assistant", "content": None, "tool_calls": [tool_call]},
                    {"role": "tool", "tool_call_id": tool_call.id, "content": str(tool_result)}
                ]
            )
            return final_response.choices[0].message.content
        
        return message.content
    
    def get_system_prompt(self) -> str:
        return """你是一个专业的客服助手。你可以：
1. 查询订单状态 - 使用 query_order 工具
2. 处理退换货申请 - 使用 create_return_request 工具
3. 查询物流信息 - 使用 query_logistics 工具
4. 解答常见问题

请保持友好、专业的态度，准确理解用户需求。"""
    
    async def execute_tool(self, tool_name: str, arguments: str) -> any:
        """执行MCP工具"""
        import json
        params = json.loads(arguments)
        result = await self.mcp_session.call_tool(tool_name, params)
        return result

# 运行示例
async def main():
    agent = CustomerServiceAgent()
    await agent.connect_to_mcp()
    
    # 模拟用户对话
    user_messages = [
        "你好，我想查询订单 12345 的状态",
        "这个订单可以退货吗？",
        "退货流程是什么？"
    ]
    
    for msg in user_messages:
        print(f"用户: {msg}")
        response = await agent.process_message(msg)
        print(f"客服: {response}\n")

if __name__ == "__main__":
    asyncio.run(main())
```

from mcp.server import Server
from mcp.types import Tool, TextContent
import json

server = Server("order-server")

# 模拟订单数据库
ORDERS_DB = {
    "12345": {
        "status": "已发货",
        "items": ["iPhone 15 Pro", "AirPods Pro 2"],
        "total": 10998.00,
        "shipping_date": "2026-02-10",
        "tracking_number": "SF1234567890"
    },
    "12346": {
        "status": "待发货",
        "items": ["MacBook Air M3"],
        "total": 8999.00,
        "shipping_date": None,
        "tracking_number": None
    }
}

@server.list_tools()
async def list_tools():
    return [
        Tool(
            name="query_order",
            description="查询订单状态和详情",
            inputSchema={
                "type": "object",
                "properties": {
                    "order_id": {
                        "type": "string",
                        "description": "订单编号"
                    }
                },
                "required": ["order_id"]
            }
        ),
        Tool(
            name="create_return_request",
            description="创建退货申请",
            inputSchema={
                "type": "object",
                "properties": {
                    "order_id": {"type": "string"},
                    "reason": {"type": "string"},
                    "items": {"type": "array", "items": {"type": "string"}}
                },
                "required": ["order_id", "reason"]
            }
        ),
        Tool(
            name="query_logistics",
            description="查询物流信息",
            inputSchema={
                "type": "object",
                "properties": {
                    "tracking_number": {"type": "string"}
                },
                "required": ["tracking_number"]
            }
        )
    ]

@server.call_tool()
async def call_tool(name: str, arguments: dict):
    if name == "query_order":
        order_id = arguments.get("order_id")
        order = ORDERS_DB.get(order_id)
        if order:
            return [TextContent(type="text", text=json.dumps(order, ensure_ascii=False))]
        return [TextContent(type="text", text=f"未找到订单 {order_id}")]
    
    elif name == "create_return_request":
        order_id = arguments.get("order_id")
        reason = arguments.get("reason")
        return [TextContent(type="text", 
            text=f"退货申请已创建: 订单{order_id}, 原因:{reason}, 申请号:RET-{order_id}")]
    
    elif name == "query_logistics":
        tracking = arguments.get("tracking_number")
        # 模拟物流信息
        logistics = {
            "tracking_number": tracking,
            "status": "运输中",
            "current_location": "上海转运中心",
            "estimated_delivery": "2026-02-16",
            "history": [
                {"time": "2026-02-15 14:00", "location": "上海转运中心", "status": "到达"},
                {"time": "2026-02-14 20:00", "location": "深圳发货中心", "status": "发出"}
            ]
        }
        return [TextContent(type="text", text=json.dumps(logistics, ensure_ascii=False))]

if __name__ == "__main__":
    server.run()

# 缓存常用工具结果
from functools import lru_cache
import hashlib

def cache_key(func_name: str, params: dict) -> str:
    """生成缓存键"""
    param_str = json.dumps(params, sort_keys=True)
    return hashlib.md5(f"{func_name}:{param_str}".encode()).hexdigest()

class ToolCache:
    def __init__(self, ttl: int = 300):
        self.cache = {}
        self.ttl = ttl
    
    async def get_or_call(self, func, params: dict):
        key = cache_key(func.__name__, params)
        
        if key in self.cache:
            result, timestamp = self.cache[key]
            if time.time() - timestamp < self.ttl:
                return result
        
        result = await func(**params)
        self.cache[key] = (result, time.time())
        return result

### 2. 监控与日志

```python
import logging
from dataclasses import dataclass
from datetime import datetime

@dataclass
class ToolCallMetrics:
    tool_name: str
    duration_ms: float
    success: bool
    error_message: str = None
    timestamp: datetime = None
    
    def __post_init__(self):
        if self.timestamp is None:
            self.timestamp = datetime.now()

class ToolMonitor:
    def __init__(self):
        self.metrics = []
        self.logger = logging.getLogger("mcp.monitor")
    
    async def execute_with_monitoring(self, tool_func, *args, **kwargs):
        """带监控的工具执行"""
        start_time = time.time()
        tool_name = tool_func.__name__
        
        try:
            result = await tool_func(*args, **kwargs)
            duration = (time.time() - start_time) * 1000
            
            metric = ToolCallMetrics(
                tool_name=tool_name,
                duration_ms=duration,
                success=True
            )
            self.metrics.append(metric)
            
            self.logger.info(f"工具 {tool_name} 执行成功，耗时 {duration:.2f}ms")
            return result
            
        except Exception as e:
            duration = (time.time() - start_time) * 1000
            
            metric = ToolCallMetrics(
                tool_name=tool_name,
                duration_ms=duration,
                success=False,
                error_message=str(e)
            )
            self.metrics.append(metric)
            
            self.logger.error(f"工具 {tool_name} 执行失败: {e}")
            raise
    
    def get_statistics(self) -> dict:
        """获取工具调用统计"""
        if not self.metrics:
            return {}
        
        total_calls = len(self.metrics)
        success_calls = sum(1 for m in self.metrics if m.success)
        avg_duration = sum(m.duration_ms for m in self.metrics) / total_calls
        
        tool_stats = {}
        for metric in self.metrics:
            if metric.tool_name not in tool_stats:
                tool_stats[metric.tool_name] = {"calls": 0, "errors": 0}
            tool_stats[metric.tool_name]["calls"] += 1
            if not metric.success:
                tool_stats[metric.tool_name]["errors"] += 1
        
        return {
            "total_calls": total_calls,
            "success_rate": success_calls / total_calls,
            "average_duration_ms": avg_duration,
            "tool_breakdown": tool_stats
        }
```

### 3. 错误处理与降级

```python
from typing import Optional
import random

class ToolExecutor:
    def __init__(self, max_retries: int = 3, timeout: float = 30.0):
        self.max_retries = max_retries
        self.timeout = timeout
        self.fallback_tools = {}
    
    async def execute_with_fallback(self, tool_name: str, params: dict) -> any:
        """执行工具，失败时使用备用方案"""
        try:
            return await self.execute_with_retry(tool_name, params)
        except Exception as e:
            self.logger.warning(f"主工具 {tool_name} 失败，尝试备用方案: {e}")
            
            # 检查是否有备用工具
            if tool_name in self.fallback_tools:
                fallback = self.fallback_tools[tool_name]
                return await fallback(params)
            
            # 返回友好错误信息
            return {"error": "服务暂时不可用，请稍后重试", "original_error": str(e)}
    
    async def execute_with_retry(self, tool_name: str, params: dict) -> any:
        """带重试的工具执行"""
        last_error = None
        
        for attempt in range(self.max_retries):
            try:
                return await asyncio.wait_for(
                    self.execute_tool(tool_name, params),
                    timeout=self.timeout
                )
            except asyncio.TimeoutError:
                last_error = "执行超时"
            except Exception as e:
                last_error = str(e)
            
            # 指数退避
            if attempt < self.max_retries - 1:
                wait_time = (2 ** attempt) + random.uniform(0, 1)
                self.logger.info(f"第 {attempt + 1} 次重试，等待 {wait_time:.2f} 秒...")
                await asyncio.sleep(wait_time)
        
        raise Exception(f"工具执行失败（已重试{self.max_retries}次）: {last_error}")
```
