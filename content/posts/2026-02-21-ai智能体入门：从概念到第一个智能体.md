## 核心概念介绍

### 什么是AI智能体？

AI智能体（AI Agent）是一种能够**感知环境、自主决策、执行动作**的人工智能系统。与传统的大型语言模型（LLM）不同，智能体不仅仅是回答问题，它能够：

- **自主规划**：将复杂任务分解为可执行的步骤
- **工具调用**：使用外部API、数据库、搜索引擎等工具
- **记忆管理**：保存和利用历史对话及执行记录
- **迭代优化**：根据执行反馈不断调整策略

### 智能体 vs 传统LLM

| 特性 | 传统LLM | AI智能体 |
|------|---------|----------|
| 交互方式 | 一问一答 | 多轮自主执行 |
| 信息获取 | 依赖训练数据 | 实时调用工具 |
| 任务处理 | 单步骤完成 | 多步骤规划执行 |
| 记忆能力 | 上下文窗口有限 | 长期记忆存储 |

### 智能体的核心组件

```

├─────────────┬─────────────┬─────────────┤
```

## 为什么需要这个技术

### 1. 弥补LLM的局限性

大语言模型虽然强大，但存在明显短板：
- **知识截止**：无法获取实时信息
- **计算能力**：不擅长精确数学计算
- **外部集成**：无法直接操作外部系统

### 2. 自动化复杂工作流

智能体能够处理需要多步骤协作的任务：
- 📧 自动读取邮件 → 提取关键信息 → 生成回复草稿
- 🔍 搜索资料 → 整理总结 → 生成报告
- 🗓️ 查看日程 → 协调时间 → 发送会议邀请

### 3. 持续学习和优化

通过记忆机制，智能体能从过去的交互中学习：
- 记住用户偏好
- 积累领域知识
- 优化执行策略

## 工作原理详解

### ReAct范式（Reasoning + Acting）

ReAct是当前最流行的智能体架构，它将推理和行动紧密结合：

```
思考(Thought) → 行动(Action) → 观察(Observation) → 思考(Thought) → ...
```

**执行循环示例：**

1. **用户提问**："今天上海天气怎么样？"
2. **智能体思考**：用户想知道天气，我需要调用天气API
3. **选择工具**：`get_weather(city="上海")`
4. **执行行动**：调用天气API
5. **观察结果**：获取到天气数据
6. **再次思考**：已获取数据，可以回答用户
7. **生成回复**："今天上海晴，温度15-22°C..."

### 规划与任务分解

对于复杂任务，智能体会进行多层级规划：

```
任务：规划一次日本旅行

└── 子任务1: 确定目的地
    ├── 查询热门景点
    ├── 了解当地文化
    └── 确定行程天数

└── 子任务2: 预订交通
    ├── 查询航班
    ├── 比较价格
    └── 预订机票

└── 子任务3: 预订住宿
    ├── 搜索酒店
    ├── 查看评价
    └── 完成预订
```

## 基础用法示例

### 示例1：最简单的智能体

```python
from langchain.agents import AgentType, initialize_agent
from langchain_openai import ChatOpenAI
from langchain.tools import Tool
import os
from dotenv import load_dotenv

load_dotenv()

# 定义工具
def get_weather(city: str) -> str:
    """获取指定城市的天气信息"""
    # 这里可以接入真实的天气API
    weather_data = {
        "北京": "晴，15-25°C",
        "上海": "多云，18-26°C",
        "深圳": "小雨，22-28°C"
    }
    return weather_data.get(city, "暂无该城市天气数据")

# 创建工具列表
tools = [
    Tool(
        name="get_weather",
        func=get_weather,
        description="获取指定城市的天气信息，输入参数为城市名称"
    )
]

# 初始化语言模型
llm = ChatOpenAI(
    model="gpt-3.5-turbo",
    temperature=0
)

# 创建智能体
agent = initialize_agent(
    tools=tools,
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True
)

# 运行智能体
response = agent.run("今天上海天气怎么样？")
print(response)
```

**运行结果：**
```
> 进入Agent执行链...

思考：用户想知道上海的天气，我需要使用get_weather工具。
行动：get_weather
行动输入：上海

观察：多云，18-26°C

思考：我已经获取到了上海的天气信息，现在可以回答用户了。
最终答案：今天上海多云，温度在18到26摄氏度之间。
```

### 2. 错误处理与重试

```python
from langchain.agents import AgentExecutor
from tenacity import retry, stop_after_attempt, wait_fixed

# 配置重试策略
agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    max_iterations=5,  # 最大迭代次数
    early_stopping_method="generate",  # 超限时生成答案
    handle_parsing_errors=True  # 自动处理解析错误
)

@retry(stop=stop_after_attempt(3), wait=wait_fixed(1))
def run_with_retry(query: str) -> str:
    """带重试机制的智能体执行"""
```
