# RAG入门：让大模型拥有外部知识

## 什么是RAG

**RAG（Retrieval-Augmented Generation，检索增强生成）** 是一种将信息检索技术与大型语言模型（LLM）相结合的AI架构。简单来说，RAG让大模型在回答问题之前，先从外部知识库中检索相关信息，然后基于这些信息生成答案。

想象你是一位医生，面对一个罕见病例。你不会仅凭记忆下诊断，而是会先查阅最新的医学文献、病例数据库，然后再给出专业的诊断意见。RAG就是给大模型配备了一个这样的"知识库查询系统"。

### RAG的核心价值

1. **解决知识截止问题**：大模型的训练数据有截止日期，RAG让它能访问最新信息
2. **减少幻觉（Hallucination）**：基于检索到的事实生成答案，而非凭空编造
3. **可追溯性**：可以查看答案引用的原始资料来源
4. **成本效益**：无需重新训练模型即可更新知识

---

## 为什么需要RAG

### 传统LLM的局限性

| 问题 | 说明 | 影响 |
|------|------|------|
| 知识陈旧 | 训练数据截止于某一时间点 | 无法回答时事、新产品等问题 |
| 幻觉问题 | 对不确定的问题编造答案 | 降低可信度，可能产生误导 |
| 领域局限 | 对专业领域知识掌握不足 | 垂直行业应用效果差 |
| 无法引用 | 无法告知答案来源 | 难以验证和审计 |

### RAG的典型应用场景

1. **企业知识库问答**
   - 内部文档、规章制度查询
   - 产品手册和技术文档问答
   - 客服知识库自动回复

2. **智能客服**
   - 基于商品信息的推荐
   - 订单状态和政策查询
   - 售后问题诊断

3. **教育辅助**
   - 教材内容的智能答疑
   - 个性化学习资料推荐
   - 学术论文辅助阅读

4. **医疗咨询**
   - 医学文献检索问答
   - 病例相似度匹配
   - 用药指导查询

5. **法律研究**
   - 法规和判例检索
   - 合同审查辅助
   - 法律意见生成

## RAG工作原理

### 架构概览

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   用户查询   │────▶│  检索系统    │────▶│  相关知识   │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                                │
                       ┌────────────────────────┘
                       ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   生成答案   │◀────│  大语言模型  │◀────│  增强提示   │
└─────────────┘     └─────────────┘     └─────────────┘
```

### 核心流程

**第一步：文档预处理（离线阶段）**

```
原始文档 → 文本分块 → 向量化 → 存入向量数据库
```

1. **文档加载**：读取PDF、Word、网页等各种格式的文档
2. **文本分割**：将长文档切分成适当大小的文本块（chunk）
   - 常见大小：200-500 tokens
   - 重叠区域：10-20%，保持上下文连贯性
3. **向量化**：使用嵌入模型将文本转换为向量
   - OpenAI text-embedding-3-small/large
   - 开源模型：sentence-transformers/all-MiniLM-L6-v2
4. **存储**：将向量+原文存入向量数据库

**第二步：检索增强（在线阶段）**

```
用户问题 → 问题向量化 → 相似度检索 → 获取Top-K文本块
```

1. **查询编码**：将用户问题转换为向量
2. **相似度计算**：在向量空间中找到最相似的文本块
3. **结果排序**：按相似度排序，取Top-K（通常5-10个）

**第三步：答案生成**

```
检索结果 + 用户问题 → 构建增强提示 → LLM生成答案
```

典型提示模板：
```
基于以下参考资料回答问题：

[参考资料1]
{chunk_1}

[参考资料2]
{chunk_2}

...

问题：{user_question}

请基于以上资料回答，如果资料不足请说明。
```

### 关键技术组件

| 组件 | 功能 | 常用选择 |
|------|------|----------|
| 嵌入模型 | 文本向量化 | OpenAI Embeddings、Hugging Face模型 |
| 向量数据库 | 存储和检索向量 | Chroma、Pinecone、Milvus、Qdrant |
| 重排序器 | 精排检索结果 | Cohere Rerank、Cross-Encoder |
| 大语言模型 | 生成答案 | GPT-4、Claude、Llama等 |

```python
"""文档加载模块 - 支持多种文档格式"""

from pathlib import Path
from typing import List
from langchain.document_loaders import (
    PyPDFLoader,
    TextLoader,
    UnstructuredWordDocumentLoader
)
from langchain.schema import Document

class DocumentLoader:
    """多格式文档加载器"""
    
    def __init__(self, data_dir: str):
        self.data_dir = Path(data_dir)
        self.loaders = {
            '.pdf': PyPDFLoader,
            '.txt': TextLoader,
            '.docx': UnstructuredWordDocumentLoader,
            '.md': TextLoader
        }
    
    def load_file(self, file_path: Path) -> List[Document]:
        """加载单个文件"""
        ext = file_path.suffix.lower()
        if ext not in self.loaders:
            print(f"不支持的文件格式: {ext}")
            return []
        
        loader_class = self.loaders[ext]
        loader = loader_class(str(file_path))
        documents = loader.load()
        
        # 添加源文件信息
        for doc in documents:
            doc.metadata['source'] = str(file_path)
            doc.metadata['file_type'] = ext
        
        return documents
    
    def load_directory(self) -> List[Document]:
        """加载整个目录"""
        all_documents = []
        
        for file_path in self.data_dir.rglob('*'):
            if file_path.is_file() and file_path.suffix in self.loaders:
                print(f"正在加载: {file_path}")
                docs = self.load_file(file_path)
                all_documents.extend(docs)
        
        print(f"共加载 {len(all_documents)} 个文档片段")
        return all_documents
```

**2. 文本分块处理 (`src/text_processor.py`)**

```python
"""文本处理模块 - 分块和清洗"""

from typing import List
from langchain.schema import Document
from langchain.text_splitter import RecursiveCharacterTextSplitter

class TextProcessor:
    """智能文本处理器"""
    
    def __init__(
        self,
        chunk_size: int = 500,
        chunk_overlap: int = 50,
        separators: List[str] = None
    ):
        """
        参数:
            chunk_size: 每个文本块的大小（字符数）
            chunk_overlap: 块之间的重叠字符数
            separators: 优先使用的分隔符列表
        """
        self.separators = separators or ["\n\n", "\n", "。", "；", " ", ""]
        self.splitter = RecursiveCharacterTextSplitter(
            chunk_size=chunk_size,
            chunk_overlap=chunk_overlap,
            separators=self.separators,
            length_function=len
        )
    
    def split_documents(self, documents: List[Document]) -> List[Document]:
        """将文档分块"""
        chunks = self.splitter.split_documents(documents)
        
        # 添加分块信息到metadata
        for i, chunk in enumerate(chunks):
            chunk.metadata['chunk_index'] = i
            chunk.metadata['chunk_size'] = len(chunk.page_content)
        
        print(f"文档分块完成: {len(documents)} → {len(chunks)} 个片段")
        return chunks
    
    def clean_text(self, text: str) -> str:
        """清洗文本"""
        # 移除多余空白
        text = ' '.join(text.split())
        # 移除特殊字符
        text = text.replace('\x00', '')
        return text.strip()
```

```python
"""向量存储模块 - 管理和查询向量数据库"""

import os
from typing import List, Optional
from langchain.schema import Document
from langchain_openai import OpenAIEmbeddings
from langchain_chroma import Chroma
from langchain.embeddings import HuggingFaceEmbeddings

class VectorStoreManager:
    """向量存储管理器"""
    
    def __init__(
        self,
        persist_directory: str = "./vector_db",
        embedding_model: str = "openai",  # 或 "huggingface"
        collection_name: str = "documents"
    ):
        self.persist_directory = persist_directory
        self.collection_name = collection_name
        
        # 初始化嵌入模型
        if embedding_model == "openai":
            self.embeddings = OpenAIEmbeddings(
                model="text-embedding-3-small"
            )
        else:
            # 使用开源模型，无需API Key
            self.embeddings = HuggingFaceEmbeddings(
                model_name="sentence-transformers/all-MiniLM-L6-v2"
            )
        
        self.db = None
    
    def create_from_documents(self, documents: List[Document]) -> Chroma:
        """从文档创建向量数据库"""
        print("正在创建向量数据库...")
        
        # 确保目录存在
        os.makedirs(self.persist_directory, exist_ok=True)
        
        self.db = Chroma.from_documents(
            documents=documents,
            embedding=self.embeddings,
            persist_directory=self.persist_directory,
            collection_name=self.collection_name
        )
        
        print(f"向量数据库创建完成，存储位置: {self.persist_directory}")
        return self.db
    
    def load_existing(self) -> Optional[Chroma]:
        """加载已有的向量数据库"""
        if not os.path.exists(self.persist_directory):
            print("向量数据库不存在，请先创建")
            return None
        
        self.db = Chroma(
            persist_directory=self.persist_directory,
            embedding_function=self.embeddings,
            collection_name=self.collection_name
        )
        print("向量数据库加载成功")
        return self.db
    
    def add_documents(self, documents: List[Document]):
        """向现有数据库添加文档"""
        if self.db is None:
            self.create_from_documents(documents)
        else:
            self.db.add_documents(documents)
            print(f"已添加 {len(documents)} 个文档")
    
    def as_retriever(self, search_k: int = 5):
        """获取检索器"""
        if self.db is None:
            self.load_existing()
        
        return self.db.as_retriever(
            search_type="similarity",  # 或 "mmr" 用于多样性
            search_kwargs={"k": search_k}
        )
```

**4. RAG流程整合 (`src/rag_chain.py`)**

```python
"""RAG核心流程 - 检索和生成"""

from typing import List, Dict, Any
from langchain.schema import Document
from langchain_openai import ChatOpenAI
from langchain.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

class RAGChain:
    """RAG问答链"""
    
    # RAG提示模板
    RAG_TEMPLATE = """你是一个专业的企业知识库助手。请基于以下参考资料回答用户问题。

## 参考资料
{context}

## 回答规则
1. 仅基于提供的参考资料回答，不要添加外部知识
2. 如果资料不足以回答问题，明确说明"根据现有资料无法回答"
3. 保持回答简洁专业，突出重点
4. 如涉及具体条款，请引用来源文档

## 用户问题
{question}

请提供准确、有帮助的回答："""
    
    def __init__(self, retriever, model_name: str = "gpt-3.5-turbo"):
        self.retriever = retriever
        self.llm = ChatOpenAI(
            model=model_name,
            temperature=0.1,  # 低温度确保回答稳定
            max_tokens=1000
        )
        
        # 构建RAG链
        self.prompt = ChatPromptTemplate.from_template(self.RAG_TEMPLATE)
        
        self.chain = (
            {
                "context": self.retriever | self._format_docs,
                "question": RunnablePassthrough()
            }
            | self.prompt
            | self.llm
            | StrOutputParser()
        )
    
    def _format_docs(self, docs: List[Document]) -> str:
        """格式化文档为上下文"""
        formatted = []
        for i, doc in enumerate(docs, 1):
            source = doc.metadata.get('source', '未知来源')
            content = doc.page_content.strip()
            formatted.append(f"[资料{i}] 来源: {source}\n{content}\n")
        
        return "\n---\n".join(formatted)
    
    def query(self, question: str) -> Dict[str, Any]:
        """
        执行RAG查询
        
        返回:
            {
                'question': 原始问题,
                'answer': 生成的答案,
                'sources': 引用的来源文档列表
            }
        """
        # 获取检索结果
        retrieved_docs = self.retriever.get_relevant_documents(question)
        
        # 生成答案
        answer = self.chain.invoke(question)
        
        # 整理来源
        sources = []
        for doc in retrieved_docs:
            sources.append({
                'content': doc.page_content[:200] + "...",
                'source': doc.metadata.get('source', '未知'),
                'score': doc.metadata.get('score', None)
            })
        
        return {
            'question': question,
            'answer': answer,
            'sources': sources,
            'retrieved_count': len(retrieved_docs)
        }
```

**5. 主应用 (`app.py`)**

```python
#!/usr/bin/env python3
"""RAG企业知识库问答系统主程序"""

import os
from dotenv import load_dotenv

from src.document_loader import DocumentLoader
from src.text_processor import TextProcessor
from src.vector_store import VectorStoreManager
from src.rag_chain import RAGChain

# 加载环境变量
load_dotenv()

class RAGKnowledgeBase:
    """企业知识库RAG系统"""
    
    def __init__(self, data_dir: str = "./data/company_docs"):
        self.data_dir = data_dir
        self.vector_store = VectorStoreManager()
        self.rag_chain = None
    
    def initialize(self):
        """初始化知识库"""
        print("=" * 50)
        print("初始化企业知识库...")
        print("=" * 50)
        
        # 1. 加载文档
        loader = DocumentLoader(self.data_dir)
        documents = loader.load_directory()
        
        if not documents:
            print("错误：未找到任何文档")
            return False
        
        # 2. 文本处理
        processor = TextProcessor(
            chunk_size=500,
            chunk_overlap=50
        )
        chunks = processor.split_documents(documents)
        
        # 3. 创建向量数据库
        self.vector_store.create_from_documents(chunks)
        
        # 4. 创建RAG链
        retriever = self.vector_store.as_retriever(search_k=5)
        self.rag_chain = RAGChain(retriever)
        
        print("\n✅ 知识库初始化完成！")
        return True
    
    def load_existing(self):
        """加载已有的知识库"""
        db = self.vector_store.load_existing()
        if db:
            retriever = self.vector_store.as_retriever(search_k=5)
            self.rag_chain = RAGChain(retriever)
            return True
        return False
    
    def ask(self, question: str) -> dict:
        """提问"""
        if self.rag_chain is None:
            return {
                'error': '知识库未初始化，请先运行 initialize() 或 load_existing()'
            }
        
        return self.rag_chain.query(question)
    
    def interactive_mode(self):
        """交互式问答模式"""
        print("\n" + "=" * 50)
        print("🤖 企业知识库问答系统")
        print("输入 'quit' 退出，输入 'help' 查看帮助")
        print("=" * 50 + "\n")
        
        while True:
            try:
                question = input("\n❓ 请输入问题: ").strip()
                
                if question.lower() in ['quit', 'exit', 'q']:
```
