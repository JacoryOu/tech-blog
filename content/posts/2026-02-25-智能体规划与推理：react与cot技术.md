### 1. 核心概念介绍

#### 什么是 ReAct？

ReAct（Reasoning + Acting）是一种将推理（Reasoning）和行动（Acting）结合的技术范式。它让 AI 智能体能够在执行动作之前进行思考，并根据执行结果调整后续行动。

**ReAct 的核心循环：**
1. **Thought（思考）**：分析当前情况，决定下一步行动
2. **Action（行动）**：执行具体动作（如调用工具、搜索信息）
3. **Observation（观察）**：获取行动结果
4. **重复**：基于新观察继续思考和行动

#### 什么是 CoT（思维链）？

Chain-of-Thought（思维链）是一种提示工程技术，通过引导模型"一步一步思考"，让 AI 展示其推理过程，从而提高复杂问题的解决能力。

**CoT 的两种形式：**
- **Zero-shot CoT**：直接添加"Let's think step by step"提示
- **Few-shot CoT**：提供带有详细推理过程的示例

### 2. 为什么需要这个技术

#### 传统 AI 的局限

传统的大语言模型存在以下问题：
- **幻觉问题**：可能生成看似合理但实际错误的信息
- **缺乏可解释性**：无法了解模型是如何得出答案的
- **复杂任务处理弱**：对于多步骤问题容易出错
- **无法与外部世界交互**：只能基于训练数据回答问题

#### ReAct + CoT 的优势

| 特性 | 传统 LLM | ReAct + CoT |
|------|----------|-------------|
| 可解释性 | 低 | 高（展示推理过程） |
| 准确性 | 中等 | 高（可验证中间步骤） |
| 外部交互 | 无 | 强（可调用工具） |
| 错误恢复 | 无 | 有（根据观察调整） |

### 3. 工作原理详解

#### ReAct 的工作流程

```
用户问题 → 思考(Thought) → 行动(Action) → 观察(Observation)
     ↑                                           |
     └──────────── 循环直到得出答案 ←─────────────┘
```

```python
            "description": description
        }

        """运行 ReAct 循环"""
        context = f"Question: {query}\n\n"
        
        for i in range(self.max_iterations):
            # 构建提示

            # 获取 LLM 响应

            print(f"\n=== 第 {i+1} 轮 ===")

            # 解析思考
            if "Final Answer:" in response:
                return response.split("Final Answer:")[1].strip()
            
            # 解析行动

                action_line = response.split("Action:")[1].split("\n")[0].strip()
                action_name, action_input = self._parse_action(action_line)

                if action_name in self.tools:
```

#### 技巧 1：Self-Consistency（自一致性）

通过多次采样并选择最常见的答案来提高准确性：

```python
def self_consistency_cot(question, n_samples=5):
    """使用自一致性改进 CoT"""
    answers = []
    
    for _ in range(n_samples):
        response = chain_of_thought(question)  # 使用前面的 CoT 函数
        # 提取最终答案（假设答案在"答案："之后）
        if "答案：" in response:
            answer = response.split("答案：")[-1].strip()
            answers.append(answer)
    
    # 投票选出最常见的答案
    from collections import Counter
    most_common = Counter(answers).most_common(1)[0]
    return most_common[0], most_common[1] / n_samples

# 使用
question = "一个水箱，第一天注入一半的水，第二天注入剩余水量的1/3，第三天注入剩余水量的1/4，最后还剩15升。水箱原来有多少水？"
answer, confidence = self_consistency_cot(question, n_samples=5)
print(f"答案：{answer} (置信度: {confidence:.2%})")
```

#### 技巧 2：树状思维（Tree of Thoughts）

对于需要探索多个可能路径的问题，可以使用 ToT：

```python
class TreeOfThoughts:
    def __init__(self, llm, branching_factor=3):
        self.llm = llm
        self.branching_factor = branching_factor
    
    def solve(self, problem, steps=3):
        """使用树状搜索解决问题"""
        states = [problem]
        
        for step in range(steps):
            new_states = []
            for state in states:
                # 生成多个可能的下一步
                thoughts = self._generate_thoughts(state)
                new_states.extend(thoughts)
            
            # 评估并选择最佳状态
            states = self._evaluate_and_select(new_states)
        
        return states[0] if states else None
    
    def _generate_thoughts(self, state):
        """生成多个思考路径"""
        prompt = f"""问题：{state}
请提供 {self.branching_factor} 个不同的解决方案或下一步：
1."""
        
        response = self.llm.predict(prompt)
        # 解析多个想法
        thoughts = [t.strip() for t in response.split("\n") if t.strip()]
        return thoughts[:self.branching_factor]
    
    def _evaluate_and_select(self, states):
        """评估并选择最佳状态"""
        # 简化的评分逻辑
        scored = []
        for state in states:
            score_prompt = f"""评估以下解决方案的合理性（1-10分）：
{state}
分数："""
            try:
                score = int(self.llm.predict(score_prompt).strip())
                scored.append((state, score))
            except:
                scored.append((state, 5))
        
        # 返回得分最高的
        scored.sort(key=lambda x: x[1], reverse=True)
        return [s[0] for s in scored[:self.branching_factor]]
```

```python
            context += "相关历史信息：\n"

                context += f"- {mem}\n"
            context += "\n"

        return context

        """ReAct 循环（简化版）"""
```

### 7. 常见问题解答

**Q1: ReAct 和 CoT 有什么区别？**

A: CoT 专注于展示推理过程，而 ReAct 结合了推理和行动，允许智能体与外部世界交互。ReAct 包含了 CoT 的能力，但增加了行动维度。

**Q2: 什么情况下应该使用这些技术？**

- **CoT**：数学问题、逻辑推理、需要逐步解释的场景
- **ReAct**：需要外部信息、多步骤任务、工具调用的场景

**Q3: 如何选择合适的提示模板？**

A: 考虑以下因素：
- 问题复杂度（简单问题用 Zero-shot，复杂问题用 Few-shot）
- 领域特殊性（通用 vs 专业领域）
- 输出格式要求（是否需要结构化输出）
