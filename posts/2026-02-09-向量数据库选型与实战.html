什么是向量数据库

向量数据库（Vector Database）是一种专门用于存储和检索高维向量数据的数据库系统。在AI时代，它已经成为RAG（检索增强生成）系统的核心基础设施。

为什么需要向量数据库？

传统数据库擅长处理结构化数据（如数字、字符串），但在处理语义相似性搜索时力不从心。例如：

  • 搜索"苹果"时，传统数据库只能匹配字面相同的词
  • 向量数据库可以理解语义，同时返回"iPhone"、"水果"等相关概念

核心原理

向量数据库通过嵌入模型（Embedding Model）将文本、图像等数据转换为高维向量（通常是768维或1536维），然后使用近似最近邻（ANN）算法快速找到相似向量。

# 文本 → 向量的转换示例
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')
texts = ["机器学习", "人工智能", "苹果水果"]
embeddings = model.encode(texts)

print(f"向量维度: {embeddings.shape}")  # (3, 384)
print(f"'机器学习'和'人工智能'的相似度: {cosine_similarity([embeddings[0]], [embeddings[1]])[0][0]:.3f}")

Chroma快速入门

Chroma是最适合初学者的向量数据库，API简洁，支持Python原生集成。

安装

pip install chromadb

基础用法

import chromadb

# 创建客户端
client = chromadb.Client()

# 创建集合（相当于传统数据库的表）
collection = client.create_collection(name="documents")

# 添加文档
collection.add(
    documents=[
        "机器学习是人工智能的一个分支",
        "深度学习是机器学习的一种方法",
        "Python是数据科学的首选语言"
    ],
    metadatas=[
        {"source": "ml-intro", "category": "ai"},
        {"source": "dl-intro", "category": "ai"},
        {"source": "python-guide", "category": "programming"}
    ],
    ids=["doc1", "doc2", "doc3"]
)

# 相似性搜索
results = collection.query(
    query_texts=["什么是神经网络？"],
    n_results=2,
    where={"category": "ai"}  # 元数据过滤
)

print(results)

Pinecone云服务

Pinecone是完全托管的向量数据库，无需运维，适合快速上线。

注册与获取API Key

  1. 访问 pinecone.io
  2. 注册账号（免费版支持5万个向量）
  3. 创建Index并获取API Key

基础用法

from pinecone import Pinecone, ServerlessSpec

# 初始化
pc = Pinecone(api_key="your-api-key")

# 创建索引（仅需执行一次）
index_name = "quickstart"
if index_name not in pc.list_indexes().names():
    pc.create_index(
        name=index_name,
        dimension=1536,  # OpenAI Embedding维度
        metric="cosine",
        spec=ServerlessSpec(
            cloud="aws",
            region="us-east-1"
        )
    )

# 连接索引
index = pc.Index(index_name)

# 插入向量
index.upsert(
    vectors=[
        {
            "id": "vec1",
            "values": [0.1, 0.2, 0.3, ...],  # 1536维向量
            "metadata": {"genre": "drama", "year": 2020}
        }
    ]
)

# 查询
results = index.query(
    vector=[0.1, 0.2, 0.3, ...],
    top_k=3,
    filter={"genre": {"$eq": "drama"}}
)

与OpenAI集成

from openai import OpenAI

client = OpenAI()

def get_embedding(text):
    response = client.embeddings.create(
        input=text,
        model="text-embedding-3-small"
    )
    return response.data[0].embedding

# 文档向量化并存储
documents = ["文档1内容", "文档2内容", "文档3内容"]
vectors = [get_embedding(doc) for doc in documents]

index.upsert(vectors=[
    {"id": f"doc{i}", "values": vec, "metadata": {"text": doc}}
    for i, (vec, doc) in enumerate(zip(vectors, documents))
])

Python SDK操作

from pymilvus import connections, FieldSchema, CollectionSchema, DataType, Collection

# 连接
connections.connect("default", host="localhost", port="19530")

# 定义集合结构
fields = [
    FieldSchema(name="id", dtype=DataType.INT64, is_primary=True, auto_id=True),
    FieldSchema(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=128),
    FieldSchema(name="title", dtype=DataType.VARCHAR, max_length=512),
    FieldSchema(name="category", dtype=DataType.VARCHAR, max_length=64)
]

schema = CollectionSchema(fields, "文档向量集合")
collection = Collection("documents", schema)

# 创建索引（必须步骤，否则搜索极慢）
index_params = {
    "metric_type": "L2",
    "index_type": "IVF_FLAT",
    "params": {"nlist": 128}
}
collection.create_index(field_name="embedding", index_params=index_params)

# 插入数据
import random
entities = [
    [[random.random() for _ in range(128)] for _ in range(1000)],  # 向量
    [f"Document {i}" for i in range(1000)],  # title
    ["tech" if i % 2 == 0 else "business" for i in range(1000)]  # category
]
collection.insert(entities)

# 加载到内存
 collection.load()

# 搜索
search_params = {"metric_type": "L2", "params": {"nprobe": 10}}
results = collection.search(
    data=[[random.random() for _ in range(128)]],
    anns_field="embedding",
    param=search_params,
    limit=5,
    expr='category == "tech"',
    output_fields=["title"]
)

for result in results[0]:
    print(f"ID: {result.id}, Distance: {result.distance}, Title: {result.entity.get('title')}")

选型建议

场景1：个人学习/原型开发

推荐：Chroma

  • 零配置，pip install即用
  • 与LangChain深度集成
  • 支持内存和持久化两种模式

场景2：SaaS产品/MVP

推荐：Pinecone

  • 免运维，专注业务开发
  • 自动扩缩容
  • 全球多区域部署

场景3：企业内部知识库

推荐：Milvus / Chroma

  • 数据安全，可私有化部署
  • Milvus支持权限控制和审计

场景4：推荐系统/搜索引擎

推荐：Milvus

  • 十亿级向量支持
  • 分布式架构
  • 混合搜索（向量+标量过滤）

性能优化

1. 索引算法选择

算法 召回率 查询速度 内存占用 适用场景
FLAT 100% 慢 低 小数据集(<10K)
IVF_FLAT 高 中等 中等 通用场景
IVF_PQ 中等 快 低 超大规模数据
HNSW 高 快 高 高性能要求

2. 向量降维

如果原始向量维度过高，可以使用PCA或自动编码器降维：

from sklearn.decomposition import PCA

# 将1536维降至384维
pca = PCA(n_components=384)
reduced_vectors = pca.fit_transform(original_vectors)

3. 批量操作

避免单条插入，使用批量操作大幅提升性能：

# ❌ 低效
for doc in documents:
    collection.insert([doc])

# ✅ 高效
collection.insert(documents)  # 一次性插入

4. 元数据过滤策略

优先使用元数据过滤减少搜索空间：

# 先过滤再搜索，效率更高
collection.query(
    query_texts=["AI技术"],
    where={"$and": [
        {"category": {"$eq": "tech"}},
        {"created_at": {"$gte": 1704067200}}
    ]}
)

总结

向量数据库是AI应用的基础设施，选择合适的方案需要考虑：

  1. Chroma：最适合快速原型和学习，API友好
  2. Pinecone：托管服务，适合不想运维的团队
  3. Milvus：企业级选择，功能最全面

关键建议：

  • 小团队/MVP优先考虑Pinecone，节省运维成本
  • 数据敏感场景选择Milvus或Chroma私有化部署
  • 生产环境务必配置索引和监控
  • 关注向量维度和索引算法对性能的影响
