1. 什么是n8n

n8n（发音：n-eight-n）是一个开源的、可扩展的工作流自动化工具，由德国开发者Jan Oberhauser于2019年创建。它的核心理念是让用户通过可视化界面拖拽节点来构建自动化流程，无需编写代码。

与Zapier、Make(原Integromat)等商业自动化工具不同，n8n提供了以下独特价值：

  • 开源免费：社区版完全免费，可自托管
  • 数据隐私：数据存储在自己的服务器上
  • 无限工作流：没有Zapier那样的任务数量限制
  • AI原生支持：内置OpenAI、Claude、LangChain等AI集成

n8n的名字来源于"nodemation"（节点自动化），它的工作方式就是连接各种节点来实现自动化任务。

2. n8n的核心优势

2.1 可视化工作流设计

n8n采用画布式界面，你可以拖拽节点、连接它们，直观看到数据流动。每个节点代表一个操作：触发、数据处理、API调用等。

2.2 400+ 原生集成

内置大量预置节点：

  • 通讯：Email、Slack、Discord、Telegram
  • 存储：Google Sheets、Airtable、Notion
  • AI：OpenAI、Anthropic、HuggingFace、Pinecone
  • 开发：GitHub、GitLab、Webhook、HTTP Request

2.3 JavaScript表达式

虽然不需要写代码，但n8n支持在节点中使用JavaScript表达式处理数据：

// 提取日期
{{ new Date().toISOString().split('T')[0] }}

// 条件判断
{{ $json.status === 'completed' ? '完成' : '进行中' }}

// 数组操作
{{ $json.items.map(item => item.name).join(', ') }}

2.4 自托管能力

你可以将n8n部署在自己的服务器上：

docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

3. 安装部署

3.1 Docker 快速启动（推荐）

# 创建数据目录
mkdir -p ~/.n8n

# 启动n8n
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

访问 http://localhost:5678 即可使用。

3.2 使用 Docker Compose

创建 docker-compose.yml：

version: '3'
services:
  n8n:
    image: n8nio/n8n
    restart: always
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=your-password
    volumes:
      - ~/.n8n:/home/node/.n8n

启动：

docker-compose up -d

4. 基础概念：节点与工作流

4.1 节点类型

n8n的节点分为四类：

类型 图标 说明 示例
Trigger ⚡ 触发工作流 Schedule, Webhook, RSS
Action ⏵ 执行操作 HTTP Request, Email
Data 🗃️ 数据处理 Code, Set, Filter
Logic 🔀 逻辑控制 IF, Switch, Merge

4.2 工作流结构

一个典型的工作流包含：

  1. Trigger节点（必须有）：定义何时启动
  2. 数据处理节点：转换、过滤数据
  3. 动作节点：执行具体操作
  4. 逻辑节点：条件分支、循环

4.3 数据传递

节点之间通过JSON对象传递数据，使用 $json 访问：

{
  "id": 123,
  "title": "文章标题",
  "content": "文章内容..."
}

在表达式中引用：{{ $json.title }}

  1. 定时获取RSS源
  2. 用AI生成摘要

5.1 创建工作流

  1. 点击 Add Workflow
  2. 添加 RSS Read 节点作为触发器

5.2 配置RSS触发器

选择 RSS Read 节点：

  • URL: https://www.jiqizhixin.com/rss（机器之心）
  • Options → Return All: 开启（获取多条）

5.3 添加AI摘要节点

添加 OpenAI 节点（或 Anthropic Chat Model）：

  • Operation: Create Completion
  • Model: gpt-3.5-turbo
  • Prompt:
请为以下文章生成中文摘要，限制在100字以内：

标题：{{ $json.title }}
内容：{{ $json.contentSnippet }}

摘要：

5.4 添加发送节点

添加 Telegram 节点（或其他通讯工具）：

  • Chat ID: 你的Telegram Chat ID
  • Text:
📰 {{ $json.title }}

📝 {{ $('OpenAI').item.json.choices[0].message.content }}

🔗 {{ $json.link }}

5.5 设置定时触发

将RSS节点改为 Schedule Trigger + HTTP Request：

  • 先用 Schedule Trigger 设置每6小时执行
  • 添加 HTTP Request 节点获取RSS：
    • Method: GET
    • URL: RSS地址

或使用 RSS Trigger 节点（直接监控RSS更新）。

5.6 完整工作流JSON

{
  "name": "RSS AI摘要",
  "nodes": [
    {
      "type": "n8n-nodes-base.scheduleTrigger",
      "parameters": {
        "rule": {
          "interval": [{"field": "hours", "hours": 6}]
        }
      }
    },
    {
      "type": "n8n-nodes-base.httpRequest",
      "parameters": {
        "url": "https://www.jiqizhixin.com/rss",
        "options": {"response": {"responseFormat": "text"}}
      }
    },
    {
      "type": "n8n-nodes-base.xml",
      "parameters": {
        "mode": "toJson"
      }
    },
    {
      "type": "n8n-nodes-base.openAi",
      "parameters": {
        "resource": "completion",
        "model": "gpt-3.5-turbo",
        "messages": {
          "message": [{
            "role": "user",
            "content": "生成摘要：{{ $json.title }}"
          }]
        }
      }

6. 进阶技巧：条件分支与错误处理

6.1 IF节点实现条件分支

场景：根据文章类别发送到不同渠道

添加 IF 节点：

  • Conditions:
    • Value 1: {{ $json.category }}
    • Operation: Equal
    • Value 2: AI

输出有两个分支：

  • true: 发送到AI讨论群
  • false: 发送到综合群

6.2 错误处理

在节点设置 On Error → Continue（出错继续执行）：

  • 添加 No Operation, do nothing 节点处理错误分支
  • 或使用 Set 节点记录错误信息

6.3 循环与拆分

使用 Split In Batches 节点批量处理：

  • 一次处理10条数据
  • 避免API限流
