1. 什么是AI智能体

AI智能体（AI Agent） 是一种能够感知环境、做出决策并执行动作以实现特定目标的自主系统。与传统的大语言模型（如ChatGPT）不同，AI智能体具备以下核心能力：

1.1 核心特征

特征 说明 传统LLM对比
自主性 能够独立运行，无需人工逐步指导 LLM需要人类持续输入提示
工具使用 可以调用外部API、查询数据库、操作文件 LLM只能基于训练数据回答
记忆能力 能保存和利用历史对话、学习经验 LLM通常只有短期上下文
规划能力 能将复杂任务分解为多步骤执行 LLM单次推理，无长期规划

1.2 智能体 vs 传统LLM

传统LLM对话模式：

用户: 今天纽约天气怎么样？
LLM: 我无法获取实时天气信息，因为我没有联网能力...

AI智能体模式：

用户: 今天纽约天气怎么样？
Agent: 让我为您查询一下今天的天气。
[调用天气API]
Agent: 纽约今天天气晴朗，气温15-22°C，适宜出行！

1.3 智能体的类型

  1. 简单反射型（Simple Reflex）

    • 基于当前感知直接行动
    • 例如：如果温度>30°C，打开空调

  2. 基于模型的反射型（Model-based）

    • 维护内部状态，跟踪环境变化
    • 例如：扫地机器人记录已清扫区域

  3. 基于目标的智能体（Goal-based）

    • 有明确目标，选择能达成目标的行动
    • 例如：导航系统规划到达目的地的路线

  4. 基于效用的智能体（Utility-based）

    • 在多个可能中选择最优解
    • 例如：股票交易智能体选择收益最大的策略

  5. 学习型智能体（Learning）

    • 能从经验中改进性能
    • 例如：AlphaGo通过自我对弈提升棋艺

3. AI智能体的核心架构

3.1 ReAct架构（Reasoning + Acting）

ReAct是目前最流行的智能体架构，将推理和行动结合在一起：

思考(Thought) → 行动(Action) → 观察(Observation) → 思考...

示例流程：

用户：北京明天适合出门吗？

思考：用户询问北京的天气情况，我需要查询天气预报。
行动：调用天气API查询北京明天天气
观察：{温度: 5-12°C, 天气: 晴, 空气质量: 良}
思考：天气晴朗，温度适中，空气质量良好，适合外出。
回答：北京明天天气不错，晴朗，温度5-12°C，空气质量良，很适合出门！

5.2 实现记忆系统

创建 memory.py：

from typing import List, Dict
from datetime import datetime

class ConversationMemory:
    """对话记忆管理器"""
    
    def __init__(self, max_history: int = 10):
        self.max_history = max_history
        self.history: List[Dict] = []
    
    def add(self, role: str, content: str):
        """添加对话记录"""
        self.history.append({
            "role": role,
            "content": content,
            "timestamp": datetime.now().isoformat()
        })
        
        # 保持历史记录在限制范围内
        if len(self.history) > self.max_history:
            self.history = self.history[-self.max_history:]
    
    def get_context(self) -> str:
        """获取格式化的对话历史"""
        context = []
        for msg in self.history:
            role_name = "用户" if msg["role"] == "user" else "助手"
            context.append(f"{role_name}: {msg['content']}")
        return "\n".join(context)
    
    def clear(self):
        """清空记忆"""
        self.history = []

class UserPreferenceMemory:
    """用户偏好记忆（长期记忆）"""
    
    def __init__(self):
        self.preferences: Dict[str, any] = {}
    
    def set(self, key: str, value):
        """设置用户偏好"""
        self.preferences[key] = {
            "value": value,
            "updated_at": datetime.now().isoformat()
        }
    
    def get(self, key: str, default=None):
        """获取用户偏好"""
        pref = self.preferences.get(key)
        return pref["value"] if pref else default

    """天气查询智能体"""
    
    def __init__(self):
        self.memory = ConversationMemory(max_history=5)
        self.user_prefs = UserPreferenceMemory()
        self.system_prompt = self._build_system_prompt()
    
    def _build_system_prompt(self) -> str:
        """构建系统提示词"""
        tools_desc = []
        for name, tool in TOOLS.items():
            params = ", ".join([
                f"{k}: {v['description']}" 
                for k, v in tool["parameters"].items()
            ])
            tools_desc.append(f"- {name}({params}): {tool['description']}")
        
        return f"""你是一个友好的天气助手。你可以帮助用户查询天气信息。

可用工具：
{chr(10).join(tools_desc)}

回复规则：
1. 如果用户询问天气，使用get_weather工具获取信息
2. 回复要简洁友好，包含温度和天气状况
3. 根据天气给出实用的出行建议
4. 如果用户表达偏好（如"我喜欢晴天"），记住这些信息

当前时间：2026-02-17"""
    
    def think_and_act(self, user_input: str) -> str:
        """思考并执行动作"""
        # 添加用户输入到记忆
        self.memory.add("user", user_input)
        
        # 构建对话上下文
        messages = [
            {"role": "system", "content": self.system_prompt},
            {"role": "system", "content": f"对话历史：\n{self.memory.get_context()}"}
        ]
        
        # 添加工具定义
        functions = [
            {
                "name": name,
                "description": tool["description"],
                "parameters": {
                    "type": "object",
                    "properties": {
                        k: {"type": v["type"], "description": v["description"]}
                        for k, v in tool["parameters"].items()
                    },
                    "required": list(tool["parameters"].keys())
                }
            }
            for name, tool in TOOLS.items()
        ]
        
        # 调用LLM进行推理
        response = openai.ChatCompletion.create(
            model="gpt-3.5-turbo",
            messages=messages + [{"role": "user", "content": user_input}],
            functions=functions,
            function_call="auto"
        )
        
        message = response.choices[0].message
        
        # 检查是否需要调用工具
        if message.get("function_call"):
            function_name = message["function_call"]["name"]
            function_args = json.loads(message["function_call"]["arguments"])
            
            # 执行工具
            tool_result = self._execute_tool(function_name, function_args)
            
            # 将工具结果反馈给LLM生成最终回复
            final_response = openai.ChatCompletion.create(
                model="gpt-3.5-turbo",
                messages=messages + [
                    {"role": "user", "content": user_input},
                    {"role": "function", "name": function_name, "content": json.dumps(tool_result)}
                ]
            )
            
            reply = final_response.choices[0].message.content
        else:
            reply = message.content
        
        # 添加助手回复到记忆
        self.memory.add("assistant", reply)
        
        return reply
    
    def _execute_tool(self, name: str, args: dict) -> dict:
        """执行工具函数"""
        if name in TOOLS:
            tool_func = TOOLS[name]["function"]
            return tool_func(**args)
        return {"error": f"未知工具: {name}"}
    
    def chat(self):
        """启动交互式对话"""
        print("🌤️ 天气助手已启动！输入'退出'结束对话。\n")

                print(f"\n助手: {response}\n")

6. 进阶功能：记忆系统

6.1 短期记忆优化

使用滑动窗口策略：

class SlidingWindowMemory:
    """滑动窗口记忆"""
    
    def __init__(self, max_tokens: int = 2000):
        self.max_tokens = max_tokens
        self.history = []
    
    def estimate_tokens(self, text: str) -> int:
        """估算token数（粗略估计）"""
        return len(text) // 4  # 约4个字符1个token
    
    def add(self, message: str):
        """添加消息，自动裁剪"""
        self.history.append(message)
        
        # 计算总token
        total = sum(self.estimate_tokens(m) for m in self.history)
        
        # 如果超出限制，从最早的消息开始删除
        while total > self.max_tokens and len(self.history) > 1:
            removed = self.history.pop(0)
            total -= self.estimate_tokens(removed)

6.2 长期记忆存储

使用向量数据库存储：

import chromadb
from sentence_transformers import SentenceTransformer

class VectorMemory:
    """基于向量数据库的长期记忆"""
    
    def __init__(self, user_id: str):
        self.client = chromadb.Client()
        self.collection = self.client.get_or_create_collection(
            name=f"user_{user_id}_memory"
        )
        self.encoder = SentenceTransformer('all-MiniLM-L6-v2')
    
    def add_memory(self, content: str, metadata: dict = None):
        """添加记忆"""
        embedding = self.encoder.encode(content).tolist()
        doc_id = str(hash(content))
        
        self.collection.add(
            embeddings=[embedding],
            documents=[content],
            metadatas=[metadata or {}],
            ids=[doc_id]
        )
    
    def recall(self, query: str, top_k: int = 3):
        """回忆相关记忆"""
        query_embedding = self.encoder.encode(query).tolist()
        
        results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=top_k
        )
        
        return results["documents"][0] if results["documents"] else []
