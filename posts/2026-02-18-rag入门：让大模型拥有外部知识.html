1. 什么是RAG

RAG（Retrieval-Augmented Generation，检索增强生成） 是一种将信息检索技术与大型语言模型（LLM）结合的AI架构。它让模型在生成回答前，先从外部知识库中检索相关信息，从而提供更准确、更有时效性的答案。

简单来说，RAG = 检索（Retrieval） + 生成（Generation）

传统LLM的局限：

  • 知识截止于训练数据的时间点
  • 无法访问私有/企业内部数据
  • 可能产生"幻觉"（编造不存在的信息）

RAG的优势：

  • 实时访问最新信息
  • 使用企业私有知识库
  • 减少幻觉，提高准确性
  • 可追溯答案来源

2. 为什么需要RAG

2.1 场景一：企业客服助手

假设你是一家电商公司的技术负责人，想要搭建一个智能客服系统：

  • 问题：公司的退货政策、物流规则经常变化
  • 传统方案：每次政策更新都要重新训练模型（成本极高）
  • RAG方案：将最新政策文档存入向量数据库，问答时实时检索

2.2 场景二：医学知识问答

  • 问题：医学研究每天都在更新，模型训练数据可能过时
  • RAG方案：连接最新的医学文献数据库，确保回答基于最新研究

2.3 场景三：个人知识管理

  • 问题：个人积累了大量笔记、文章、文档，难以检索
  • RAG方案：构建个人知识库，通过自然语言问答快速找到信息

3. RAG工作原理

RAG系统的工作流程分为两个阶段：索引阶段和查询阶段。

3.1 索引阶段（离线）

原始文档 → 文本分块 → Embedding向量化 → 存入向量数据库
  1. 文档加载：读取PDF、Word、网页等各种格式的文档
  2. 文本分块（Chunking）：将长文档切分成合适大小的片段
  3. 向量化（Embedding）：使用Embedding模型将文本转换为向量
  4. 存储：将向量存入向量数据库（如Chroma、Pinecone、Milvus）

3.2 查询阶段（在线）

用户问题 → Embedding向量化 → 向量相似度检索 → 拼接上下文 → LLM生成回答
  1. 问题向量化：将用户问题转换为向量
  2. 相似度检索：在向量数据库中找出最相似的文档片段
  3. 上下文构建：将检索到的内容作为上下文
  4. LLM生成：将上下文+问题输入LLM，生成最终答案

6. 实操案例：企业知识库问答

下面我们实现一个完整的企业知识库问答系统。

6.1 完整代码实现

"""
企业知识库问答系统 - 基于RAG实现
"""
import os
from typing import List
from langchain_community.document_loaders import TextLoader, PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_community.vectorstores import Chroma
from langchain.chains import RetrievalQA
from langchain.prompts import PromptTemplate

class EnterpriseKnowledgeBase:
    """企业知识库问答系统"""
    
    def __init__(self, persist_dir: str = "./chroma_db"):
        self.persist_dir = persist_dir
        self.embeddings = OpenAIEmbeddings(
            model="text-embedding-3-small"
        )
        self.vector_store = None
        self.qa_chain = None
        
    def load_documents(self, file_paths: List[str]) -> List:
        """加载文档"""
        documents = []
        
        for file_path in file_paths:
            if file_path.endswith('.pdf'):
                loader = PyPDFLoader(file_path)
            else:
                loader = TextLoader(file_path, encoding='utf-8')
            
            docs = loader.load()
            documents.extend(docs)
            print(f"✅ 加载文档: {file_path} ({len(docs)} 页)")
        
        return documents
    
    def split_documents(self, documents: List, chunk_size: int = 500, 
                        chunk_overlap: int = 50) -> List:
        """文档分块"""
        text_splitter = RecursiveCharacterTextSplitter(
            chunk_size=chunk_size,
            chunk_overlap=chunk_overlap,
            separators=["\n\n", "\n", "。", "！", "？", " ", ""]
        )
        
        chunks = text_splitter.split_documents(documents)
        print(f"📄 文档分块完成: {len(chunks)} 个片段")
        return chunks
    
    def create_vector_store(self, chunks: List):
        """创建向量数据库"""
        self.vector_store = Chroma.from_documents(
            documents=chunks,
            embedding=self.embeddings,
            persist_directory=self.persist_dir
        )
        self.vector_store.persist()
        print(f"💾 向量数据库已保存: {self.persist_dir}")
    
    def load_vector_store(self):
        """加载已有向量数据库"""
        if os.path.exists(self.persist_dir):
            self.vector_store = Chroma(
                persist_directory=self.persist_dir,
                embedding_function=self.embeddings
            )
            print(f"📂 向量数据库已加载")
            return True
        return False
    
    def setup_qa_chain(self):
        """设置问答链"""
        # 自定义提示词模板
        prompt_template = """
你是一位专业的企业知识库助手。请根据以下检索到的上下文信息回答问题。
如果上下文中没有相关信息，请明确说明"根据现有资料无法回答该问题"。

=== 检索到的相关信息 ===
{context}

=== 用户问题 ===
{question}

=== 回答要求 ===
1. 基于提供的上下文回答
2. 回答要简洁明了
3. 如有多条相关信息，请整合后回答
4. 如果不确定，请说明不确定

请回答:"""
        
        PROMPT = PromptTemplate(
            template=prompt_template,
            input_variables=["context", "question"]
        )
        
        # 创建检索器
        retriever = self.vector_store.as_retriever(
            search_type="similarity",
            search_kwargs={"k": 5}  # 返回最相似的5个片段
        )
        
        # 创建LLM
        llm = ChatOpenAI(
            model="gpt-4o-mini",
            temperature=0.3
        )
        
        # 创建QA链
        self.qa_chain = RetrievalQA.from_chain_type(
            llm=llm,
            chain_type="stuff",
            retriever=retriever,
            return_source_documents=True,
            chain_type_kwargs={"prompt": PROMPT}
        )
        
        print("🔗 问答链设置完成")
    
    def ask(self, question: str) -> dict:
        """提问"""
        if not self.qa_chain:
            raise ValueError("请先调用 setup_qa_chain() 设置问答链")
        
        result = self.qa_chain.invoke({"query": question})
        
        return {
            "answer": result["result"],
            "sources": [doc.page_content[:200] + "..." 
                       for doc in result["source_documents"]]
        }


# ============ 使用示例 ============

def main():
    """主函数"""
    kb = EnterpriseKnowledgeBase(persist_dir="./kb_db")
    
    # 步骤1：检查是否已有向量数据库
    if not kb.load_vector_store():
        print("🚀 首次运行，需要构建知识库...")
        
        # 步骤2：加载文档（支持多个文件）
        files = [
            "company_policy.txt",  # 公司政策
            "product_manual.pdf",  # 产品手册
            "faq.txt"              # 常见问题
        ]
        documents = kb.load_documents(files)
        
        # 步骤3：文档分块
        chunks = kb.split_documents(documents)
        
        # 步骤4：创建向量数据库
        kb.create_vector_store(chunks)
    
    # 步骤5：设置问答链
    kb.setup_qa_chain()
    
    # 步骤6：开始问答
    print("\n" + "="*50)
    print("🤖 企业知识库问答系统已启动")
    print("="*50 + "\n")
    
    while True:
        question = input("\n💬 请输入问题 (输入 'quit' 退出): ")
        
        if question.lower() == 'quit':
            break
        
        result = kb.ask(question)
        
        print(f"\n📝 回答: {result['answer']}")
        print(f"\n📚 参考来源:")
        for i, source in enumerate(result['sources'], 1):
            print(f"  [{i}] {source}")


if __name__ == "__main__":
    main()

# 结合关键词检索和向量检索
from langchain.retrievers import BM25Retriever, EnsembleRetriever

# BM25关键词检索
bm25_retriever = BM25Retriever.from_documents(documents)
bm25_retriever.k = 3

# 向量检索
vector_retriever = vector_store.as_retriever(search_kwargs={"k": 3})

# 混合检索（权重可调整）

    retrievers=[bm25_retriever, vector_retriever],

)
