1. 核心概念介绍

工具链（Tool Chain） 是 AI 智能体与外部世界交互的桥梁。通过 Function Calling（函数调用）机制，AI 可以：

  • 🔍 调用搜索引擎获取实时信息
  • 🌤️ 查询天气、股价等实时数据
  • 🗄️ 访问数据库读写数据
  • 📧 发送邮件或消息通知
  • 🧮 执行复杂计算
  • 🔗 调用任意第三方 API

工具链的本质是将 AI 从"纯文本生成器"转变为"可以执行实际行动的智能代理"。

关键术语：

  • Function Calling：模型识别需要调用外部函数并生成调用参数的能力
  • Tool Schema：工具的定义格式，包含名称、描述、参数结构
  • Tool Executor：实际执行工具调用的代码逻辑

2. 为什么需要这个技术

LLM 的固有局限：

  1. 知识截止日期：无法知道今天的新闻、股价、天气
  2. 无法执行操作：不能真正发送邮件、预订酒店、创建日程
  3. 数学计算受限：复杂计算容易出错
  4. 无法访问私有数据：无法读取你的数据库或内部系统

工具链的突破：

用户："北京今天适合出门吗？"

❌ 没有工具的 AI：
"抱歉，我无法获取实时天气信息..."

✅ 有工具的 AI：
→ 调用 weather_tool(location="北京")
→ 获取：晴天，15°C，空气质量优
→ 回答："今天北京天气晴朗，气温15°C，空气质量很好，非常适合出门！"

3. 工作原理详解

工具调用的完整流程：

┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   用户提问   │ ──→ │  AI 模型    │ ──→ │  识别需调用  │
└─────────────┘     └─────────────┘     │   的工具    │
                                        └──────┬──────┘
                                               │
                                               ↓
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  生成回答   │ ←── │  模型整合   │ ←── │  执行工具   │
│  返回用户   │     │  结果并推理  │     │  返回结果   │
└─────────────┘     └─────────────┘     └─────────────┘

关键步骤详解：

  1. 工具注册：向模型声明可用的工具及其参数格式
  2. 意图识别：模型判断是否需要调用工具
  3. 参数提取：模型生成结构化的调用参数（JSON）
  4. 工具执行：系统实际执行对应的函数
  5. 结果回传：将执行结果返回给模型
  6. 回答生成：模型基于结果生成最终回答

5. 基础用法示例

示例 1：简单的计算器工具

import json
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI()

# 1. 定义工具
calculator_tool = {
    "type": "function",
    "function": {
        "name": "calculate",
        "description": "执行数学计算，支持加减乘除",
        "parameters": {
            "type": "object",
            "properties": {
                "expression": {
                    "type": "string",
                    "description": "数学表达式，如 '23 * 45'"
                }
            },
            "required": ["expression"]
        }
    }
}

# 2. 工具执行函数
def calculate(expression: str) -> str:
    try:
        # 安全计算：只允许数字和运算符
        allowed = set('0123456789+-*/.() ')
        if not all(c in allowed for c in expression):
            return "错误：表达式包含非法字符"
        result = eval(expression)
        return f"计算结果：{result}"
    except Exception as e:
        return f"计算错误：{str(e)}"

# 3. 主对话流程
def chat_with_tools(user_message):
    messages = [
        {"role": "system", "content": "你是一个 helpful 的助手，可以使用工具来完成任务。"},
        {"role": "user", "content": user_message}
    ]
    
    # 第一次调用：让模型决定是否使用工具
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=messages,
        tools=[calculator_tool],
        tool_choice="auto"
    )
    
    message = response.choices[0].message
    
    # 检查是否有工具调用
    if message.tool_calls:
        # 将模型响应加入对话历史
        messages.append({
            "role": "assistant",
            "content": message.content or "",
            "tool_calls": [tc.model_dump() for tc in message.tool_calls]
        })
        
        # 执行每个工具调用
        for tool_call in message.tool_calls:
            function_name = tool_call.function.name
            function_args = json.loads(tool_call.function.arguments)
            
            if function_name == "calculate":
                result = calculate(function_args["expression"])
                
                # 将工具结果加入对话
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": result
                })
        
        # 第二次调用：让模型基于工具结果生成回答
        final_response = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=messages
        )
        return final_response.choices[0].message.content
    
    return message.content

# 测试
print(chat_with_tools("帮我算一下 2345 * 6789 等于多少"))
# 输出：2345 乘以 6789 等于 15,920,205

7. 常见问题解答

Q: 工具调用和 RAG 有什么区别？

A:

  • RAG（检索增强生成）：AI 被动地接收检索到的信息
  • 工具调用：AI 主动决定何时、调用什么工具、传什么参数

Q: 所有模型都支持 Function Calling 吗？

A: 不是。主流支持模型：

  • OpenAI: GPT-4, GPT-4o, GPT-3.5-turbo
  • Anthropic: Claude 3 系列
  • Google: Gemini Pro
  • 开源: Llama 3.1+, Qwen2.5+

Q: 如何确保工具调用的安全性？

A:

  1. 严格的参数校验
  2. 沙箱环境执行
  3. 权限控制（谁可以调用什么）
  4. 审计日志记录
  5. 超时和重试机制

Q: 工具调用失败怎么办？

A: 将错误信息返回给模型，让模型决定：

  • 修正参数重试
  • 尝试其他工具
  • 告知用户失败原因
